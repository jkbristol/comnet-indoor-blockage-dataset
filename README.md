# LTE O-RAN teleoperation testbed: cross-layer blockage measurements and RIS-period recordings

Data and code for the article *"Cross-layer impact of indoor blockage on a software-defined LTE link for robotic teleoperation: measurements and lessons from a reconfigurable intelligent surface integration"* (J. Kaur et al., submitted to Computer Networks, manuscript COMNET-D-26-07667). Every number and figure in the article can be regenerated from the raw logs with the scripts in this repository.

Collected at the James Watt School of Engineering, University of Glasgow, between 26 December 2024 and 11 March 2025.

## Layout

```
raw/
  march2025_locations/   unchanged machine logs from 11 March 2025 (iperf3, srsENB, srsUE, video-stream statistics)
  mastlab_sessions/      3 undated mast-lab/mini-room iperf3 logs (RIS state not recorded)
  ris_control_code/      original MATLAB RIS control scripts
processed/
  iperf_uplink_timeseries.csv      per-second iperf3 goodput, both ends of the TCP connection
  ue_phy_metrics.csv               srsUE console metrics (RSRP, path loss, MCS, SNR, BLER, bitrate)
  enb_mac_metrics.csv              srsENB console metrics (CQI, MCS, PUSCH/PUCCH SNR, BLER, bitrate)
  video_stream_qoe.csv             video-stream statistics (latency, loss, FPS, jitter, PLI, pauses)
  summary_march2025.csv            per-location summary statistics
  summary_video_qoe.csv            per-session video summary statistics
  ris_videos/
    video_inventory.csv            per-recording date, room, author label, visible content, duration
    ocr_iperf_lines_all.csv        every OCR'd iperf3 line with the transfer/bitrate consistency flag
    iperf_readings_interval.csv    de-duplicated, consistency-checked readings with iperf interval times
    iperf_readings_per_second_frame.csv  per-second readings from the configuration-sweep recordings
    matlab_snr_per_configuration.csv     MATLAB SNR printout for RIS configurations 133-141 (checked by eye)
scripts/                parsing, OCR and figure scripts (Python 3, pandas, matplotlib, Pillow, tesseract, pandoc, ffmpeg)
figures/                figures generated by the scripts
```

## Reproduce

```
python3 scripts/parse_march2025.py
python3 scripts/make_figures_march2025.py
# RIS recordings: frames are extracted at 1 frame/s with ffmpeg, then
python3 scripts/ocr_frames_2x.py ; python3 scripts/ocr_parse_interval_lines.py ; python3 scripts/ocr_dedup.py
python3 scripts/ocr_frames_3x.py <video names> ; python3 scripts/ocr_parse_per_second.py
python3 scripts/make_figures_ris_videos.py
```

## What the data can and cannot support

- The 11 March 2025 files are complete console logs and are the primary measurement data.
- The throughput in the iperf3 logs is **uplink** (UE to EPC): the EPC host ran `iperf3 -c <UE> -R`, and the eNB reports the matching uplink bitrate.
- Each location was measured once. Samples within a run are consecutive one-second intervals, not independent repetitions.
- Every iperf3 run ends with a period of zero goodput (72 s and 264 s for the two L2 runs, 378 s at L3, 351 s at L3-DC) before the operator stopped the test. The article excludes the final period of every run ("active" time); `processed/revision_metrics.csv` holds the article's Table 2-3 values.
- The RIS-period values are transcriptions of screen recordings, not machine logs. An OCR line is kept only if the transferred bytes and the bitrate agree (bitrate = bytes x 8 / 1 s within 2%). Recordings from different days, rooms and carrier settings are not paired comparisons.
- The RIS operates at 3.75 GHz. The 11 March carrier was 3579.9 MHz downlink / 3479.9 MHz uplink (10 MHz, 50 PRB, FDD). One December 2024 recording shows EARFCN 3350.
- Files whose location was not recorded are labelled as such and not inferred.

## Revision analyses (Computer Networks, R1)
Run after the scripts above, in this order:
- `scripts/ue_timeline.py` — complete one-second srsUE timeline with RRC events -> `processed/ue_timeline.csv`
- `scripts/align_ue_iperf.py` — piecewise alignment of UE and EPC iperf3 series -> `processed/aligned_timeline.csv`, `processed/ue_to_iperf_map.csv`
- `scripts/align_null_test.py` — over-fitting check of the alignment -> `processed/alignment_null_test.csv`
- `scripts/crosslayer_revision.py` — all revised paper numbers (one exclusion rule), BLER sources, RNTI check, zero-goodput classification, RLF epochs, video PLI vs RLF -> `processed/revision_metrics.csv` and others
- `scripts/within_run_variability.py` — block-bootstrap intervals -> `processed/within_run_variability.csv`
- `scripts/make_figures_revision.py` — `figures/fig_aligned_timeline.*`, `figures/fig_rlf_epochs.*`
`processed/revision_metrics.csv` is the authoritative source for the revised Tables 2-3.

## Not included

The 17 smartphone screen recordings of the RIS period and two supporting demo videos are not in this repository because of their size; the OCR readings extracted from them are in `processed/ris_videos/`. They are available from the corresponding author on request.
